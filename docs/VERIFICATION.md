## Repeat the checks

```sh
make test
.venv/bin/python tests/runtime_smoke.py
.venv/bin/python tests/public_games_smoke.py
make -C games/py2ports_snake setup PYTHON=python3.12
make -C games/py2ports_snake test
make -C games/py2ports_breakout setup PYTHON=python3.12
make -C games/py2ports_breakout test
```

The public-game script validates both actual ZIPs, runs packaged entrypoints and
game tests in an ARM64 container, checks shared-cache reuse and executes local
installation/upgrade/rollback simulations. CI initializes only the two named
public games and uploads only their ZIPs and public checksum file. It never
fetches future private games or receives private-source credentials.

## Hardware checks still required

Actual handheld SSH authentication, kernel loop mounting, Ports discovery,
fullscreen presentation, physical controller mappings, Mali rendering and
firmware/ABI compatibility remain unverified. Both games are silent; runtime
container audio checks do not establish device audio compatibility.

The profile requires ARM64 glibc Linux with compatible device-supplied SDL2,
Mali/EGL/GLES/GBM/DRM libraries. Container dummy-driver tests do not establish
hardware compatibility. Additional native dependencies require an engineered
runtime profile. ZIP/SquashFS timestamps are not promised to be byte-identical.
Backups remain until removed; saves outside `PY2PORTS_DATA_DIR` are not migrated.
